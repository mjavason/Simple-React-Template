🔑 Design Style = Visual Language + UX Philosophy + Cultural Context
Most popular styles have names (some from design history, others from tech communities), and they usually fall into these meta-categories:

1. Neumorphism
Keywords: soft shadows, subtle gradients, raised/sunken UI, tactile.
Vibe: Feels like clay or soft plastic.
Use when: You want a futuristic, soft, minimalist interface.
Tooling: Lots of shadow tweaking; box-shadow, border-radius.
Example: Neumorphism.io

2. Glassmorphism
Keywords: blur, translucency, frosted-glass effect, vibrant gradients.
Vibe: Like UI elements floating on glass in bright light.
Use when: You want a modern, clean, semi-futuristic aesthetic (think iOS 15).
Tooling: backdrop-filter: blur(), semi-transparent borders.
Example: macOS/iOS widgets.

3. Minimalist / Flat Design
Keywords: flat colors, no shadows, clean typography, whitespace-heavy.
Vibe: Clean, businesslike, no visual fluff.
Use when: You want speed, clarity, and responsiveness.
Tooling: Tailwind is built for this.
Example: Stripe's early dashboards, Notion.

4. Material Design
Keywords: elevation (shadows), color theory, floating action buttons, motion.
Vibe: Google’s design language—clean, interactive, structured.
Use when: You want polished mobile/web UX that feels “Google-like.”
Tooling: Material UI, animations.
Example: Android apps, Google apps.

5. Skeuomorphism (Retro)
Keywords: real-world texture mimicry, stitched leather, brushed metal, wood.
Vibe: Nostalgic, tactile, real.
Use when: You want throwback or highly aesthetic vintage experiences.
Tooling: Custom images, shadows, CSS gradients.
Example: Old iOS apps, hipster sites.

6. Brutalism
Keywords: raw HTML/CSS look, intentional "ugliness", sharp contrast, zero polish.
Vibe: Anti-design. It screams “I’m not here to please.”
Use when: You want to stand out, be unconventional, or make a point.
Tooling: Minimal styling, large type, jarring colors.
Example: Hacker sites, zines.

7. Swiss/International Style
Keywords: grids, sans-serif typography, strict alignment, function > form.
Vibe: Clean, precise, typographically rich.
Use when: You care about legibility, grids, and information architecture.
Tooling: CSS Grid, typography systems.
Example: Clean blogs, modern newspapers.

8. Claymorphism
Keywords: bubbly, bright, 3D-ish, soft shadows, exaggerated UI.
Vibe: Cartoonish, fun, friendly.
Use when: You’re building playful UIs (ed-tech, finance for kids, gamified UX).
Tooling: Strong box shadows + high border radius.
Example: Interfaces with avatars, fun onboarding flows.

9. Dark Mode Aesthetics
Keywords: soft lights, low contrast on dark, careful hue usage.
Vibe: Cool, sleek, coder-friendly.
Use when: You're targeting devs, night users, or gaming communities.
Tooling: Careful contrast ratios, focus on legibility.
Example: Discord, GitHub dark theme, VS Code.

10. Brutalist
Keywords: Unique, breaks all the rules

🧠 How to Choose (Meta-Heuristic)
Serious business SaaS:	 Minimal / Material
Futuristic cool app:	 Neumorphism / Glassmorphism
Fun or kid-oriented:	 Claymorphism
Retro / Hipster:	 Skeuomorphism / Brutalism
Developer tool:		 Dark Mode + Swiss
Artistic / Experimental: Brutalism / Glassmorphism
Lightweight MVP:	 Flat Design (with Tailwind)
