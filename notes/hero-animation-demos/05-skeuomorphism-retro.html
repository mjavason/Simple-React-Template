Skeuomorphism / Retro

Physical metaphor. Motion suggests weight, pressure, mechanical movement, or an object being revealed.

Strategy A: Physical assembly

Built to be felt

MODEL 7
Sequence
Background surface appears, physical-looking objects slide into position, headline and controls settle.
Motion
Directional translation, opacity, restrained overshoot.
Use when
Layered objects, devices, instruments, retro interface elements.

Strategy B: Mechanical activation

Turn it on

STANDBYON AIR
Sequence
A dial rotates, an indicator lights up, the display state reveals the product's purpose, CTA becomes prominent.
Motion
Rotation, glow state transition, crossfade of display text.
Use when
Hero built around a recognizable physical control or machine.

Strategy C: Object spotlight

No. 7

Cast in brass

Solid, heavy, made to last for decades.

Sequence
Main object is revealed through a mask, light changes subtly across it, supporting copy appears.
Motion
clip-path, small scale, translating highlight band.
Use when
A single textured object or retro product image dominates.

Avoid: Making every element bounce. Physical motion needs consistent weight and believable stopping behavior.
